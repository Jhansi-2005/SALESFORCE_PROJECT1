# Day 4 – Lightning Web Components

## What is LWC?

Lightning Web Components (LWC) is Salesforce's modern user interface framework. It uses web technologies such as HTML, JavaScript, and CSS to build fast, reusable, and maintainable user interfaces.

## What did I build?

I created a Lightning Web Component named `placementHome` for the Placement Management System.

The component displays:

* Welcome to Vishnu Placement Portal
* Today's Date
* Student Name
* Roll Number
* Department
* Welcome Message
* Application Status
* Number of Companies
* Number of Jobs
* Applications Submitted

## LWC Files

### HTML File

`placementHome.html` contains the page layout, text, and buttons.

### JavaScript File

`placementHome.js` contains variables, logic, and button-click events.

### Meta XML File

`placementHome.js-meta.xml` makes the component available in Lightning App Builder.

## What I Learned

* What Lightning Web Components are
* The structure of an LWC
* How to create an LWC
* How to use data binding
* How to display JavaScript variables in HTML
* How to handle button-click events
* How to change values using JavaScript
* How to deploy an LWC to a Lightning Page

## Component Features

* Displays student information
* Displays placement statistics
* Shows a welcome message when the button is clicked
* Changes the application status from `Not Applied` to `Applied`
